## 3. 构建主机依赖

WSL2 Ubuntu 24.04（当前环境）：

~~~bash
apt-get install -y mmdebstrap qemu-user-static binfmt-support debootstrap \
  cpio gzip xz-utils zstd rsync e2fsprogs mtools \
  meson ninja-build pkg-config dpkg-dev python3-venv git \
  gcc-aarch64-linux-gnu g++-14-aarch64-linux-gnu libstdc++-14-dev-arm64-cross
~~~

- 需要 /proc/sys/fs/binfmt_misc/qemu-aarch64 已注册（当前环境已启用）；
- mmdebstrap 用 Debian 13 keyring（config/debian-archive-keyring.gpg），不用 Ubuntu 自带旧 keyring；
- 04-build-mesa 需要 g++-14 交叉编译器与 meson >= 1.4（脚本会在私有 venv 里装新 meson）。

## 4. 快速开始

~~~bash
cd /root/MT6891-Mainline

# 1) 内核先编译（已有产物可跳过）
./scripts/build.sh

# 2) 一键构建用户空间（首次约 30-90 分钟，qemu-user 下 apt 较慢）
sudo debian/scripts/build-all.sh

# 只想分步：
sudo debian/scripts/00-mkrootfs.sh
sudo debian/scripts/01-install-desktop.sh
sudo debian/scripts/02-configure-rootfs.sh
sudo debian/scripts/03-install-kernel.sh
sudo debian/scripts/04-build-mesa.sh
sudo debian/scripts/05-mkinitramfs.sh
sudo debian/scripts/06-mkrootfs-image.sh
sudo debian/scripts/07-mkbootimg.sh
~~~

可选参数：

- build-all.sh --skip-gnome：只做 minbase rootfs 与打包；
- build-all.sh --skip-mesa：先用 Debian 自带 Mesa（llvmpipe）跑通，再单独补 G77。

产物：

| 文件 | 说明 |
| --- | --- |
| out/chopin-rootfs.img | ext4（3.7 GB，resize2fs -M 后的最小尺寸） |
| out/chopin-rootfs.sparse.img | Android sparse（2.9 GB），32 位 fastboot 可刷 |
| out/initramfs.cpio.gz | busybox initramfs |
| out/boot-chopin-debian.img | 内核 + initramfs 的 boot.img |
| out/mesa/libgallium-*.so | G77 版 libgallium |

## 5. 版本锁

config/versions.env 是唯一版本来源：

- DEBIAN_SUITE=trixie，DEBIAN_RELEASE=13.7；
- MESA_VERSION=25.0.7-2+deb13u1 —— 必须等于 rootfs 里 libgl1-mesa-dri 的版本，
  否则 libEGL_mesa 的符号版本对不上，EGL 会加载失败；
- MESA_TARBALL_URL / MESA_TARBALL_SHA256 —— Debian 官方 mesa_25.0.7.orig.tar.xz，
  本地缓存并校验（GitHub clone 在国内只有 ~10 KB/s，镜像 ~3 MB/s）；
- MESA_COMMIT=b52e2e3a —— 参考 mesa 仓库的 G77 补丁与 chopin/build.sh 来源，
  已导出到 config/（0001-panfrost-add-mali-g77.patch、mesa-build.sh）；
- 内核 release 从 linux/include/config/kernel.release 读取，不写在版本文件里。

升级 Mesa / Debian 点版本时，改 versions.env 并重跑 01（更新包）与 04（重编 .so）。

## 6. 刷机（Windows）

先备份原厂 boot 与 dtbo（项目里已有 chopin/images/boot_a.img 等）。

构建产物已同步到 Windows 工作区 D:\MT6891-Mainline\out\：

- boot-chopin-debian.img（19 MB）
- chopin-rootfs.sparse.img（2.9 GB，sparse）
- SHA256SUMS-debian

刷机脚本已复制到 D:\MT6891-Mainline\scripts\flash-debian.ps1：

~~~powershell
cd D:\MT6891-Mainline
# 手机进 fastboot
.\scripts\flash-debian.ps1
# 只刷 boot：
.\scripts\flash-debian.ps1 -SkipRootfs
# 只刷 rootfs：
.\scripts\flash-debian.ps1 -SkipBoot
~~~

注意：

- fastboot.exe 是 32 位，raw 镜像大于 2 GB 会 std::bad_alloc；必须用 sparse 镜像；
- userdata 会被整段覆盖，Android 数据不可恢复；
- 刷写中断导致 slot 切换时：fastboot getvar current-slot，再 fastboot --set-active=a；
- 恢复原厂：fastboot flash boot chopin/images/boot_a.img（dtbo 同理）。

## 7. 首启检查（设备上，串口或 tty0）

~~~bash
uname -a                          # 7.3.4-ga9777a8559e0-dirty
cat /etc/debian_version           # 13.7
systemctl is-system-running       # running / degraded
systemctl --failed                # 看失败单元
ls /sys/class/drm                 # card0-DSI-1
cat /sys/class/drm/card0-DSI-1/status
modetest -M mediatek -c           # 1080x2400
eglinfo -B                        # Mali-G77 (Panfrost)
kmscube                           # 连续跑 10 分钟
loginctl list-sessions            # wayland 会话
journalctl -b -u gdm3 --no-pager | tail -50
~~~

USB 串口：Windows 侧 COMx，115200 8N1，DTR+RTS；设备侧 /dev/ttyGS0 有 getty。
网络：RNDIS 需在设备上 touch /etc/chopin-gadget-rndis 后重启 gadget 服务，
主机拿 192.168.42.100，设备 192.168.42.2，可 ssh chopin@192.168.42.2。

## 8. 故障排查

| 现象 | 先看 | 处理 |
| --- | --- | --- |
| 卡 logo，无输出 | 串口、pstore | 换回原厂 boot；检查 initramfs 是否打包 |
| initramfs 找不到 rootfs | 启动打印的 label/设备 | 确认 userdata 已刷 sparse；blkid 看 LABEL |
| 进 multi-user 但无图形 | journalctl -u gdm3 | 先跑 modetest / kmscube 分层定位 |
| eglinfo 显示 llvmpipe | libgallium 版本 | dpkg -W libgl1-mesa-dri；重跑 04 |
| gdm 反复重启 | gdm 日志 EGL/GBM | 设 WaylandEnable=false 试 X11；再试 Flashback |
| USB 无串口 | /sys/class/udc、dmesg | 确认 configfs gadget 已建；看 chopin-gadget 日志 |
| 无 WiFi | ip link、dmesg | NVRAM 缺失，走 RNDIS/SSH，后续补固件 |

## 9. 回滚

- 只换内核：fastboot flash boot 原厂 boot_a.img；
- rootfs 坏了：重刷 userdata（会清空 Debian 数据）；
- 桌面起不来：gdm3 配置改 WaylandEnable=false，或 systemctl set-default multi-user.target 先保串口。

## 10. 已知限制

- 显示栈是 vendor mediatek_v2，GBM/atomic 在 mutter 下尚未验证；
- panfrost 的 chopin 时钟钩子未在持续负载下验证；
- WiFi/BT 缺 NVRAM；音频/相机未验证；
- 充电/电量依赖 MT6360，i2c5 问题未修；
- GNOME 在 1080x2400 上的缩放需要实机调（dconf 先给 1.25，可能还要 monitors.xml 设 2x）。
